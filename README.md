# CassutoTech GitHub Pages files

These are the current static website files for CassutoTech.

## Upload

1. Extract this ZIP.
2. Open the extracted folder.
3. Upload every file and folder inside it to the root of the GitHub Pages repository.
4. Keep `CNAME` in the root and do not rename the `assets` folder.
5. In GitHub, open **Settings → Pages**.
6. Choose the branch and root folder that contain these files.
7. Set the custom domain to `cassutotech.com`.

The package is already built for the custom domain root. Do not upload the ZIP itself, the source project, or the private-preview server files.
