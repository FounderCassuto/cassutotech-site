# CassutoTech website

This folder contains the static CassutoTech business website prepared for GitHub Pages.

## Included

- Responsive desktop and mobile layout
- Working call, text, email, and copy-email actions
- CassutoTech CT logo and browser-tab icon
- Search metadata, business schema, robots.txt, and sitemap
- Custom-domain file for `cassutotech.com`

The website has no paid dependencies, server, database, or build step. GitHub Pages can publish these files directly.
