# CassutoTech website

This folder contains the current CassutoTech website prepared for GitHub Pages.

## Upload instructions

1. Extract the ZIP file.
2. Upload every individual file in this folder to the root of the GitHub repository.
3. Do not upload the ZIP file or the containing folder itself.
4. Keep the `CNAME` file and `.nojekyll` file in the repository.

## Included features

- Mobile-first navy, gray, and copper layout
- Four-question support text builder
- Custom service-routing layout with no stock or generated imagery
- Service-day request with preferred and backup days plus a time preference
- Clear work-approval and Southern Illinois service-area records
- Working Call, Text, Email, and desktop Copy email actions
- Android and Apple message-app handling
- Correct contact email: `founder.cassutotech@gmail.com`
- Current CassutoTech phone number: `618-816-5274`
- Search metadata, browser icon, robots.txt, sitemap, and custom-domain file

The website uses plain HTML, CSS, and JavaScript. It has no paid dependencies, server, database, or build step.
